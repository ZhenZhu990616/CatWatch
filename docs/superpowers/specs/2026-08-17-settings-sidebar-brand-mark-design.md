# 设置侧边栏品牌图标设计说明

## 目标

在 CatGPT 设置面板左侧边栏底部增加应用图标，作为低强调度的品牌标记，不影响现有导航选项的阅读与点击。

## 布局

- 图标固定为约 34 pt 的正方形并水平居中。
- 图标位于侧边栏列表下方，顶部留 8 pt、底部留 14 pt。
- 不增加标题、分割线、卡片背景或点击行为。
- 不改变侧边栏宽度、列表内边距、分组顺序或右侧内容布局。

## 视觉与外观

- 优先加载应用包内的 `AppIcon.icns`，确保与 Dock 图标一致。
- Debug 环境缺少 `.icns` 时使用同构图 SwiftUI 兜底绘制，保持猫耳、嘴巴和胡须一致。
- 深色外观整体透明度约 0.78，浅色外观约 0.60，避免黑白图标在磨砂背景上突兀。
- 图标不添加额外阴影、边框或动画。

## 无障碍

品牌图标使用“CatGPT”作为无障碍标签，不参与导航选择。

## 验收标准

1. 深色和浅色设置面板中，图标均出现在左侧栏底部且不遮挡列表。
2. 图标与 Dock 图标构图一致；Debug 无资源时仍显示正确的兜底图形。
3. 图标尺寸、透明度和间距在普通窗口尺寸下不抢夺导航焦点。
4. Debug 构建与现有测试通过，不执行 Release 构建。
