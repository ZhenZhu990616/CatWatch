# CatGPT 应用图标设计说明

## 目标

保留现有 CatGPT 图标的黑色圆角背景与白色极简猫耳主体，只增加小嘴巴和对称胡须，并移除眼睛，保持参考稿的单一特征提取风格。

## 视觉约束

- 背景继续使用黑色圆角方形，不增加渐变、阴影或额外装饰。
- 猫耳主体的几何轮廓不变。
- 嘴巴使用小尺寸黑色负空间线条，位置位于主体下半部中央。
- 胡须使用左右对称的短线条，避免在 16 pt / 32 pt 图标尺寸下糊成面部轮廓。
- 不加入眼睛、鼻子、文字或品牌标识。

## 实现边界

图标继续由 `Scripts/generate-app-icon.swift` 以 Core Graphics 绘制并生成 macOS `.icns` 多尺寸资源；不新增运行时依赖，也不使用外部位图素材。

## 验收标准

1. 生成脚本能成功输出包含 16 pt 至 512 pt @2x 的 `.icns`。
2. 猫耳主体、黑色背景与原轮廓保持一致。
3. 输出图标没有眼睛，只有小嘴巴和对称胡须。
4. Swift Debug 构建与现有测试不受影响；不执行 Release/签名发布流程。
