# 批量截图缓存设计

## 目标

让 CatWatch 在不落盘的前提下暂存最多 8 张截图，并以一次多图片请求发送给 Codex。

- `⇧` 连按两下：截取一张与“立即截图”相同范围的画面并加入缓存。
- `Esc`：优先取消尚未完成的缓存截图；没有在途截图时删除最后一张缓存。
- “立即截图”快捷键：缓存非空时只发送缓存队列；缓存为空时保留原有单张立即截图行为。
- 缓存期间，悬浮窗只显示规则六芒星；发送开始时六芒星消失，改为现有猫爪思考状态。
- “从屏幕选择”默认快捷键从 `shift double tap` 调整为 `cmd+e`。

## 交互与状态

### 队列状态

批量缓存只在主线程维护，并有三种互斥状态：

1. **空闲**：无缓存、无截图任务；立即截图按原路径执行。
2. **缓存中**：正在截取一张待加入队列的图片；再次缓存和发送操作不启动新任务。
3. **缓存就绪**：有 1–8 张图片；立即截图发送队列，`Esc` 删除末尾图片。

发送开始后转入既有的模型请求状态，批量队列立即转移并清空。模型请求进行中禁止新增批量截图，避免 UI 与捕获状态机交叉。

### 规则

- 队列上限固定为 8 张。达到上限时不再截图，状态提示“最多缓存 8 张，请先发送”。
- 每张缓存截图使用当前 `maxImageEdge` 和当前固定区域设置生成 JPEG 数据；修改设置不会追溯影响已缓存图片。
- `Esc` 在缓存状态下处理：若正在截图，取消该截图且保留已有缓存；否则移除最后一张。删至 0 张时隐藏批量悬浮窗。
- 批量队列仅存在于内存中；退出、重启、登出后清空，不进行恢复。
- 缓存截图不要求已登录；发送时若未登录、无权限或发送前置条件失败，队列保持不变。
- 一旦请求已经开始，队列不自动恢复；网络/服务端错误按现有错误 UI 呈现，用户可重新缓存后重试。

## UI

新增 `BatchCaptureIndicatorView`，由 `ResultPanelController` 显示：

- 缓存阶段只显示按顺序横向排列的规则六芒星，不显示猫爪、计数文字或旧回答正文。
- 六芒星由单一的规则六芒星路径绘制，六个尖角清晰，尺寸为猫爪指示器的一半左右。
- 1–8 个图标依次追加；删除最后一张时移除最右侧图标。
- 开始发送时立即隐藏批量指示器并调用现有 `showPhase("sending")`，恢复猫爪动画。
- 即使最终结果配置为 Touch Bar，缓存与发送阶段仍临时使用悬浮窗提供图形反馈；最终回答继续遵循用户已选的输出模式。
- 图标数量通过无障碍标签（例如“已缓存 3 张截图”）表达，不在面板中额外显示文字。

## 实现边界

### 配置与快捷键

- 增加 `batchCaptureHotKeyText`，默认值为 `shift double tap`。
- `captureRegionHotKeyText` 默认值改为 `cmd+e`，并仅迁移仍保留旧默认值 `shift double tap` 的配置；用户自定义值不覆盖。
- 新增快捷键参与持久化、恢复默认、设置页录制、运行时注册和重复校验。
- 快捷键总数从 4 项扩展为 5 项：立即截图、框选截图、显示/隐藏结果、从屏幕选择、批量截图。
- 为批量状态安装受控的 Escape 监听；该监听只在队列非空或缓存任务进行时处理，并避开设置录制器和选择覆盖层的本地 Escape 行为。

### 捕获与发送

- 提取批量队列类型（例如 `BatchCaptureQueue`），保存有序 `[Data]` 和一个在途 `Task`。
- 队列捕获复用 `Screenshotter.captureImageData(maxEdge:region:)`，因此保持 ScreenCaptureKit 对 CatWatch 自身窗口的排除逻辑。
- `LLMClient` 新增多图片分析入口，把 prompt 放在同一条 user content 的最前方，随后按缓存顺序追加多个 `input_image` 项。
- 现有单图 `analyze(imageData:)` 通过新入口实现或保留为单图包装，避免两套请求体逻辑分叉。

## 错误处理

- 缓存截图失败：不增加图标、不改变已有队列，显示现有错误状态。
- 队列满：不截取第 9 张，不改变已缓存内容。
- 发送前失败（无登录、权限缺失、队列仍在缓存中）：不清空队列。
- 发送开始后失败：沿用结果面板错误显示，不恢复队列。
- 连续按键：缓存任务未结束时，新的批量缓存与发送请求不创建并发任务。

## 测试

- 默认值、旧“从屏幕选择”默认快捷键迁移、环境变量和持久化。
- 快捷键重复校验覆盖新增的批量快捷键。
- 队列：追加顺序、上限 8、删除末尾、缓存中取消、删至 0。
- 立即截图：队列为空走单图；队列非空走多图且不额外截图。
- 发送前错误保留队列；发送开始后错误清空队列。
- 多图片请求体按正确顺序包含 prompt 与所有图片。
- 批量 UI：显示图标数、隐藏正文和猫爪、发送时恢复猫爪、无障碍标签。

## 非目标

- 不新增磁盘缓存、历史会话恢复、拖拽排序、图片缩略图预览或单张编辑。
- 不改变现有框选截图立即发送的含义。
